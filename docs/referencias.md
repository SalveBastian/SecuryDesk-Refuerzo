# Referencias técnicas

- OWASP Foundation. **OWASP Top 10:2021**. Riesgos comunes en aplicaciones web. https://owasp.org/Top10/
- OWASP Foundation. **Application Security Verification Standard (ASVS)**. Controles verificables de seguridad de aplicaciones. https://owasp.org/www-project-application-security-verification-standard/
- IETF. **RFC 7519 - JSON Web Token (JWT)**. https://www.rfc-editor.org/rfc/rfc7519
- NIST. **SP 800-61 Rev. 2 - Computer Security Incident Handling Guide**. https://csrc.nist.gov/publications/detail/sp/800-61/rev-2/final
- NIST. **SP 800-53 Rev. 5 - Security and Privacy Controls for Information Systems and Organizations**. https://csrc.nist.gov/publications/detail/sp/800-53/rev-5/final
- PostgreSQL Global Development Group. **PostgreSQL Documentation - Backup and Restore**. https://www.postgresql.org/docs/current/backup.html
- Express.js. **Security Best Practices: Production**. https://expressjs.com/en/advanced/best-practice-security.html
- Prisma. **Prisma ORM Documentation**. https://www.prisma.io/docs/
- npm package documentation: `bcryptjs`, `zod`, `express-rate-limit`, `helmet`, `morgan`, `jsonwebtoken`.

Las referencias se usan para justificar prácticas generales; la evidencia del proyecto se basa en el código y las pruebas incluidas en este repositorio.
